Right now I’m interested in how technically complex products can still feel calm and easy to follow.

That includes questions like:

- How dense can a UI become before it stops helping?
- What kinds of metadata actually improve decision-making?
- How should writing change inside technical products?

I keep running into these questions in my projects, so I’m paying closer attention to them as I build.
